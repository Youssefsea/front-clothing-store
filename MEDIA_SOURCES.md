# VANTA media sources

The default hero uses a public Unsplash image URL selected for a fashion/editorial visual direction.

Default image:
https://images.unsplash.com/photo-1529139574466-a303027c1d8b

Optional hero video:
Set NEXT_PUBLIC_HERO_VIDEO_URL to a video URL from a source with rights suitable for your deployment. The app falls back to the editorial image when the video is empty or fails.

No proprietary Nike, Adidas, Puma, Zara, or Uniqlo campaign assets are bundled.
